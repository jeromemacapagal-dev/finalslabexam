# Final submission checklist

Use this checklist before submitting the CC211 finals laboratory examination.

## Project content
- [ ] Replace the student-name and section placeholders in `README.md`.
- [ ] Read the HTML, CSS, and JavaScript and make sure you can explain them.
- [ ] Compare `PROMPT_LOG.md` techniques with the exact frameworks taught in class; add missing class-specific entries.
- [ ] Test valid, empty, too-short, and past-date task form submissions.
- [ ] Add, complete, reopen, search, filter, sort, and delete a task.
- [ ] Bookmark a resource, switch to Saved, refresh, and confirm it remains saved.
- [ ] Check a mobile-width layout and a desktop-width layout.
- [ ] Check browser console and verify there are no unresolved app errors.
- [ ] Capture real browser screenshots of the desktop page, mobile layout, and a working interaction in this folder (the included `preview-*` files are static render previews).

## GitHub
- [ ] Create an instructor-accessible GitHub repository.
- [ ] Use Git Bash or CMD; do not upload only through the GitHub website.
- [ ] Make at least three meaningful commits.
- [ ] Push the project and verify all expected files on GitHub.
- [ ] Save a real successful-push screenshot as `git-successful-push.png`.
- [ ] Save a real commit-history screenshot as `git-commit-history.png`.
- [ ] Add the actual repository URL to the submission form or README.
