# Screenshot folder

The `preview-*.png` files are static page-render previews created from the app markup and stylesheet with sample content. They are included to show the intended interface, but they are **not** live browser captures and do not prove interactive behavior.

Before submission, run StudyNest in your browser and add real screenshots for:

- `application-overview.png` — desktop overview/dashboard.
- `application-mobile.png` — mobile layout.
- `application-working-feature.png` — a working interaction, such as adding a task or saving a resource.
- `git-successful-push.png` — terminal showing the successful command-line push.
- `git-commit-history.png` — terminal showing at least three meaningful commits.
